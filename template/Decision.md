# Decisions

Accepted project decisions only. Newest entry first.

## Entry template

### YYYY-MM-DD — <decision>

- **Decision ID:** <stable ID, e.g. DEC-2026-001>
- **Status:** ACCEPTED | REPLACED
- **Type:** CONTEXT | DIRECTION | IMPLEMENTATION | RELEASE | EVOLVE | WAIVER
- **Scope:** <what this decision applies to>
- **Decision:** <the chosen direction or rule>
- **Basis:** <evidence, constraint, or human preference>
- **Reviewed artifacts:** <path + artifact ID/version + SHA-256 for each exact file or diff>
- **Approved by:** <human name>
- **Approved on:** <YYYY-MM-DD and timezone>
- **Authorizes:** <what work may proceed>
- **Does not authorize:** <what remains outside scope>
- **Gate transition:** <from → to, or NONE>
- **Replaces:** <previous entry, or none>

Approval applies only to the exact artifact versions and hashes above. A later
revision needs a new decision or an explicit replacement entry.
